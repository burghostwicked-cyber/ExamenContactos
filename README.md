# ExamenContactos

Proyecto de la clase de Programación para Dispositivos Móviles I.

La aplicación permite registrar contactos con nombre, teléfono, país, nota y una imagen. Los datos se guardan en una base de datos SQLite.

También tiene una pantalla para ver los contactos guardados, buscarlos, editarlos, eliminarlos y compartirlos. Desde otra pantalla se puede confirmar una llamada al número seleccionado.

## Cómo probar la aplicación

Abrir el proyecto en Android Studio, esperar que cargue y ejecutarlo en un teléfono o emulador Android.

Para comprobar su funcionamiento, se puede guardar un contacto y luego buscarlo en la lista.
